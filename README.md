# GraphQL Application

This is a GraphQL-based application built by following Pedro's tutorial. The project demonstrates how to use Apollo Server, Apollo Client, GraphQL queries, mutations and resolvers to create a simple app.

## 🚀 Technologies Used
- Apollo Server
- Apollo Client
- GraphQL
- JavaScript

## 📌 Features
- Fetching users using GraphQL queries
- Creating, updating and deleting users with mutations
- Using `useQuery`,  `useMutation` and `useLazyQuery` in Apollo Client

## 📖 Tutorial Reference
This project was built while following Pedro's tutorial. You can check out his content [here](https://www.youtube.com/watch?v=16bHGKe1QqY&list=PLpPqplz6dKxXICtNgHY1tiCPau_AwWAJU).

## 🔧 Setup & Run
1. Clone the repository:
   ```sh
   git clone https://github.com/your-repo/graphql-app.git
   ```
2. Install dependencies, both server and client
   ```
   npm install
   ```
2. Run the server
   ```sh
   npm start
   ```
4. Run the client
   ```sh
   npm start
   ```
